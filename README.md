# imjustnate.com

The home of **I'm Just Nate · Nightmares Come True** and **The Comfort Audit**.

- `index.html`: home page (imjustnate.com)
- `audit/index.html`: the Comfort Audit (imjustnate.com/audit)
- `404.html`, `favicon.svg`, `og-*.png`: page-not-found, icon and link previews
- `CNAME`: tells GitHub Pages to serve this repo at imjustnate.com

Static files only, hosted free on GitHub Pages. Answers to the audit stay in each visitor's browser.
